# Unity Junior Programmer: Project Log
A collection of projects and technical challenges completed during the Unity Junior Programmer pathway.

## 🚀 Projects & Prototypes
* **5 Core Prototypes:** Incremental projects covering player control, physics, and gameplay mechanics.
* **Error Project:** Debugging and fixing broken code to ensure project stability.
* **ModTheCube Project:** Introduction to scripting transformations and material properties.
* **Counting Prototype:** Focus on UI, scoring systems, and data flow.
* **Personal Project:** Applying learned concepts to a custom-built game environment and did these for the lab part of the pathway.
* **Resource Management:** Advanced logic for handling game states and object interactions.
